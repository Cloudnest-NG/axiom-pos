# Axiom POS Access Rights

**Axiom Cloudnest Ltd** — Odoo 18 Point of Sale access rights, layout theme, draft receipts, and print controls.

## Features

- Draft / pro forma printing for POS HR advanced employees
- Paid reprint access: Everyone, POS Administrators, or No one
- Product info / on-hand visibility controls
- Product price display rights
- POS layout theme (body + thicker header)
- Product card price badge styling
- XML draft receipt design selection
- Print shortcuts in header and ticket screen
- Apply settings to all POS configs in the company

## Dependencies

- `point_of_sale`
- `pos_hr`
- `odoo-pos-custom-branding`
