Axiom POS Access Rights

POS permissions, theme layout, draft receipts & print controls for Odoo 18

Overview

Axiom POS Access Rights gives shop managers precise control over what cashiers can see and print in the Point of Sale. Configure screen layout colors, product price badges, draft / pro forma receipt designs, paid reprint rules, and product info visibility — per POS config, with optional company-wide copy.

Built for Odoo 18 with full POS HR support (basic employee vs advanced / admin cashier roles).

Key Features

Access & roles

  • Draft / pro forma printing for POS HR advanced (admin) employees
  • Paid reprint access: Everyone, POS Administrators, or No one
  • First paid print always allowed; reprint rights apply only on reprint
  • Product info / on-hand: Everyone, Administrators, or No one
  • Show or hide product prices on cards and order lines

Theme & receipts

  • POS layout theme from two config colors (body + thicker header)
  • Product card price badge: colors, 9 alignments, font size
  • Select an XML draft receipt design (pos.receipt)
  • Print shortcuts in the POS header and ticket list
  • Apply Axiom settings to all POS configs in the company

Configuration

Go to Point of Sale → Configuration → Settings (or open a POS config) and use the Axiom sections under Interface / Bills & Receipts:

  1. Set POS Screen Theme background and text colors.
  2. Style the Product Card Price badge.
  3. Choose who can see Product Info / On Hand.
  4. Select a Draft Order Receipt Design from Receipt Designs.
  5. Configure Paid Order Reprinting access.
  6. Optionally Apply to all POS in the company.

Re-open the POS session after saving so theme and rights load for cashiers.

Dependencies

  • point_of_sale
  • pos_hr
  • odoo-pos-custom-branding (XML receipt designs / pos.receipt)

Compatibility

  • Odoo 18.0 Community / Enterprise
  • Works with POS HR employee login (basic vs advanced cashiers)
